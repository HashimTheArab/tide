# @tide-ota/server

A read-only Expo Updates server. `@tide-ota/server/workers` is the Cloudflare Workers entry over an R2 binding;
`@tide-ota/server/node` serves S3-compatible or disk storage on Node.

Setup and documentation: [github.com/HashimTheArab/tide](https://github.com/HashimTheArab/tide#readme).
