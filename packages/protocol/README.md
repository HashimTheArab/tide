# @tide-ota/protocol

The Expo Updates protocol v1 code shared by [`@tide-ota/server`](https://www.npmjs.com/package/@tide-ota/server) and
[`@tide-ota/cli`](https://www.npmjs.com/package/@tide-ota/cli): manifests, multipart replies, code signing and bsdiff
patches, on web-standard APIs only (Workers, Node and browsers).

You don't need to install it yourself: it comes with the server and the CLI, and its version always matches theirs.
Part of [Tide](https://github.com/HashimTheArab/tide), a self-hosted Expo Updates server.
