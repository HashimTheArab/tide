# Hermes delta compiles: Tide conformance app, Expo SDK 58

Generated by `pnpm hermes-delta` from the JSON file of the same name beside this file. Android bundles. Bases: the embedded bundle and an OTA export of the app's start tree, and an OTA export one update later (the OTA base); each change is a patch onto that update. Plain bundles are expo export's hermesc command recompiled on fixed relative names; delta bundles add -base-bytecode.

Patch bytes are Tide's makeBsdiff output, each checked with checkPatch. Tide stores a patch only when its bytes times two are at most the gzip-9 size of the new bundle (packages/cli/src/publish-patch.ts keepsPatch).
Each cell gives the patch to the plain bundle, then to the bundle delta-compiled against the compile base;
reused means the base is that bundle, so Tide stores no patch and the device downloads nothing.
